Meridian — how a material code becomes a national identity

Six stages, deterministic first. Every arrow is a real API boundary; the stack under each stage is what actually runs it.

01 · IMPORT
Four masters, four house styles

Each CPSE uploads its own material master and purchase history. Columns are detected, units normalised to a base unit, nothing is altered.

Two seats, one rule

A CPSE steward answers questions and decides within its own codes. Only the national approver may join two CPSEs' codes. Every decision is signed and hash-chained.

Out: approvals, answers, refusals — each an append-only event with SHA-256 chain

One national code

A confirmed identity is minted once: UNSPSC class, a permanent serial, a Luhn check digit. Every source code is mapped to it additively — nothing is renamed or deleted.
